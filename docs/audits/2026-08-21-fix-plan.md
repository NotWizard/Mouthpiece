# Mouthpiece 修复计划 — 2026-08-21 审计（基线 HEAD b3747451 / v2.0.10）

本文件是修复工作的唯一真相源与进度台账。每完成一项：更新“状态”，单独提交一个 commit（中英双语，遵循 AGENTS.md），并在 CHANGELOG.md [Unreleased] 追加一条。
状态取值：TODO / DEV-DONE / REVIEWED / COMMITTED（附 commit 短哈希）/ BLOCKED（附原因）。

## 流程约束（每一项都必须遵守）
1. 角色分离：负责实现的 agent 与负责复核的 agent 必须不同。复核 agent 独立读改动 + 跑测试，判定 PASS/FAIL 并给证据；FAIL 则退回重修，不得自我批准。
2. 每项修复必须留下可运行的回归测试（除非纯 UI，需注明手动验证步骤）。测试计数只增不减（基线 116）。
3. 每项独立 commit；提交前必须 `xcodebuild ... test` 全绿 + swiftformat/swiftlint/shellcheck 无新增告警。
4. 根因修复，禁止创可贴。已证伪/降级项按本表标注处理。
5. 遇阻塞：标 BLOCKED + 原因，继续下一项，最后统一汇报。
