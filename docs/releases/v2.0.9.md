# v2.0.9: 翻译组合键触发更可靠

修复按下翻译组合键后偶尔没有进入翻译模式、输出原文的问题。

## 🐛 Bug 修复

- 修复了使用翻译组合键（听写键 + 后缀键）时，翻译偶尔不生效、插入的仍是未翻译原文的问题。原因是翻译会话在切换的瞬间可能被同时触发的普通听写会话抢占，且失败时没有任何提示。现在翻译会话切换会自动重试确保生效。
- 调试日志现在会标记翻译会话、记录组合键被忽略或翻译切换失败的原因，便于后续排查。

# v2.0.9: More Reliable Translation Hotkey

Fixes the translation combo occasionally not kicking in and inserting the untranslated original text.

## 🐛 Bug fixes

- Fixed the translation hotkey (dictation key + suffix) occasionally not taking effect, leaving an untranslated transcript. The translation session could be silently preempted by a simultaneously triggered normal dictation session during the switch-over; the switch now retries to make sure translation wins.
- Debug logs now tag translation sessions and record why a combo press was ignored or a translation switch failed, making future reports diagnosable.
