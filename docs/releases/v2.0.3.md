# v2.0.3: 告别卡死、剪贴板更安心、长录音更轻快

这个版本集中解决了网络不稳时听写"僵住"的一系列问题，并让长时间录音明显更省内存。

## ✨ 改进

- 30 分钟以上的长录音转写时占用的内存大幅下降（峰值约降低三分之二），长时间听写更流畅。
- 出错时的提示现在直接显示服务商的原始原因（例如"API key 无效"），不再是一大段看不懂的原始报文。
- 关闭调试日志后，现在真正做到什么都不记录；此前部分会话信息仍会写入系统日志。
- 本地模型下载的完整性校验更严格，损坏或不完整的模型文件不会再被安装后导致崩溃。

## 🐛 Bug 修复

- 修复了关闭"在 Dock 中显示"后，打开应用时主窗口闪一下就沉到其他窗口（如终端）背后的问题，现在窗口会稳定停留在最前面。
- 修复了网络不稳（切换 Wi-Fi、VPN 断开等）时听写永远停在"整理中"或画面不再更新的问题：连接失去响应最多 60 秒内会明确报错，结束听写也有 8 秒兜底，自动改用已有内容完成转写，不再无限等待。
- 修复了两次听写间隔很近时，第二次可能把你剪贴板里的原有内容覆盖丢失的问题。
- 修复了组合快捷键（如 ⌘K）先松开修饰键时，听写卡在"按住"状态不停止的问题。
- 修复了合盖休眠唤醒后，胶囊可能停留在屏幕外看不到的问题。
- 另有十余项稳定性修复（快速重启听写、取消时机、热键吞键等边缘场景），完整列表见仓库 CHANGELOG。

# v2.0.3: No More Stuck Sessions, Safer Clipboard, Lighter Long Recordings

This release focuses on the family of "dictation freezes when the network wobbles" issues, and makes long recordings much lighter on memory.

## ✨ Improvements

- Transcribing recordings longer than 30 minutes now uses far less memory (peak roughly cut by two thirds), keeping long sessions smooth.
- Error messages now show the provider's actual reason (for example "Invalid API key") instead of a wall of raw response text.
- Turning off debug logging now truly logs nothing; previously some session details still reached the system log.
- Downloaded local models are validated more strictly, so a corrupted or incomplete model file can no longer be installed and crash transcription.

## 🐛 Bug fixes

- Fixed the main window flashing open and then dropping behind other windows (such as Terminal) when launching the app with "Show in Dock" turned off — it now stays reliably in front.
- Fixed dictation staying at "Finalizing" forever, or the live transcript silently freezing, when the connection goes half-dead (Wi-Fi switch, VPN drop): an unresponsive server now surfaces a clear error within 60 seconds, and finishing a session falls back to the text already captured after 8 seconds instead of waiting indefinitely.
- Fixed your clipboard contents being lost when two dictations finish within about a second of each other.
- Fixed combination hotkeys (such as ⌘K) getting stuck "held down" when the modifier key is released first.
- Fixed the capsule ending up stranded off-screen after waking your Mac from sleep.
- Plus a dozen more stability fixes for edge cases (rapid restarts, cancellation timing, swallowed hotkey events); see the repository CHANGELOG for the full list.
