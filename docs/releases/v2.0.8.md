# v2.0.8: 热键更可靠、收尾不丢字、历史全量可搜

本次共落地 39 项内部审计改进，涵盖稳定性、隐私与日常体验。

## ⚠️ 注意

- 听写历史现在会自动清理：仅保留最近 90 天、至多 2000 条记录。需要长期留存的内容请及时复制导出。
- 翻译功能现在依赖"文字整理"：打开翻译会自动启用文字整理，关闭文字整理会同时关闭翻译（凭证配置沿用文字整理的设置）。

## 🎉 新功能

- 历史页搜索现在覆盖全部记录（此前只搜最近 200 条），列表支持"加载更多"分页浏览。
- 概览页新增"上次错误"卡片：听写失败后可完整查看、复制错误信息，不再只有一闪而过的提示。
- 胶囊状态变化现在会通过旁白（VoiceOver）播报，视障用户可感知录音/完成/失败。
- 首次引导可跳过录音验证步骤；辅助功能权限缺失时侧栏会显示警示并可一键直达系统设置。

## ✨ 改进

- 说完立即停止也不会丢掉最后几个字：停止时会先送完全部剩余音频再定稿。
- 录音途中断开耳机/拔掉麦克风会立刻收到"麦克风连接中断"提示，不再假装仍在录音。
- 网络抖动时若已识别出部分文字，会保留这些文字完成会话，而不是直接报错作废。
- 配错 API Key 现在在开始听写时就会提示，而不是录到一半才失败；错误信息也会标明是哪家服务。
- 完全没说话的录音会直接提示"未检测到语音"，不再上传整段静音（也避免了模型静音幻觉）。

## 🐛 Bug 修复

- 修复了开启翻译后，其他应用的 `Cmd+,`（打开设置）快捷键被全局吞掉的问题。
- 修复了按住说话期间切回本应用后松键不停止录音的问题。
- 修复了热键可录成单个字母键、导致任意打字都会触发听写的问题。
- 另有二十余项修复与加固（提示音缓存、日志脱敏、迁移备份凭证清理、发布链校验等），完整清单见仓库 CHANGELOG。

# v2.0.8: Reliable Hotkeys, No Lost Endings, Full-History Search

This release lands 39 improvements from an internal audit across stability, privacy, and everyday use.

## ⚠️ Heads-up

- Dictation history is now auto-pruned: the most recent 90 days and up to 2000 entries are kept. Copy out anything you need to keep long-term.
- Translation now depends on Text Processing: enabling translation turns it on automatically, and turning Text Processing off also disables translation (credentials come from the Text Processing settings).

## 🎉 New features

- History search now covers all records (previously only the latest 200), with "Load more" pagination.
- The overview page gains a "Last error" card: after a failed dictation you can read and copy the full error instead of catching a 2-second toast.
- The capsule announces state changes through VoiceOver, so recording/finish/failure are perceivable without sight.
- Onboarding's recording check can be skipped, and a sidebar banner with a System Settings shortcut appears when Accessibility permission is missing.

## ✨ Improvements

- Stopping right after you finish speaking no longer drops the last words — all remaining audio is delivered before finalizing.
- Unplugging your microphone or losing the headset mid-recording now shows "microphone connection interrupted" immediately instead of pretending to keep recording.
- If the network stutters after some text was already recognized, the session completes with that text instead of failing outright.
- A wrong API key now fails right at the start of dictation with the provider's name in the message, not halfway through a recording.
- Fully silent recordings report "no speech detected" instead of uploading the whole clip (which also avoids silence hallucinations).

## 🐛 Bug fixes

- Fixed translation mode swallowing every app's `Cmd+,` (Open Settings) shortcut globally.
- Fixed push-to-talk not stopping when the key was released after switching back to Mouthpiece.
- Fixed the hotkey recorder accepting a bare letter key, which made ordinary typing trigger dictation.
- Plus twenty-odd further fixes and hardening items (cue caching, log redaction, migration-backup credential cleanup, release-chain checks); see the repository CHANGELOG for the full list.
