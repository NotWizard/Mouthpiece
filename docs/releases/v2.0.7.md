# v2.0.7: 切换麦克风即用，自身窗口听写不再闪退

修复两个影响日常使用的问题：换麦克风后听写起不来，以及对着应用自己的输入框听写会闪退。

## 🐛 Bug 修复

- 修复了切换麦克风（如连接/断开蓝牙耳机、更换输入设备）后开始听写报"麦克风启动失败"、且重启应用才能恢复的问题。现在换完设备立刻就能正常听写，录音中途切换麦克风也能无缝继续采集。
- 修复了在 Mouthpiece 自己的窗口里（词典、提示词编辑、历史搜索框）听写时，文字插入瞬间应用闪退的问题。现在照常插入，应用稳定运行。

# v2.0.7: Dictate Right After Switching Mics, No More Crash in Our Own Windows

Fixes two everyday issues: dictation refusing to start after a microphone change, and a crash when dictating into the app's own text fields.

## 🐛 Bug fixes

- Fixed dictation failing with "Starting the microphone failed" after switching microphones (connecting/disconnecting a Bluetooth headset, changing input devices), which previously required relaunching the app. Dictation now starts right away after a device change, and even switching microphones mid-recording keeps capturing seamlessly.
- Fixed the app quitting unexpectedly the moment text was inserted when dictating into Mouthpiece's own windows (dictionary, prompt editor, history search). Insertion now works normally and the app stays stable.
