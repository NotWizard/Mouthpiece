# v2.0.5: 百炼双实时模型与词典热词

## 🎉 新功能

- 阿里云百炼现在支持在 `Qwen Audio 3.0 ASR Flash Streaming` 和 `Fun-ASR Realtime` 之间切换。新配置默认使用 Qwen Audio，已有 Fun-ASR 配置会继续保持不变。
- 控制面板会记住所选模型，切换服务商或重新打开应用后无需重复选择。

## ✨ 改进

- “词典”中的术语会根据所选百炼模型自动采用对应的热词方式，让专有名词识别更准确。
- 每次听写严格使用当前选择的模型；发生错误时不会悄悄切换到另一个模型，结果与配置保持一致。

# v2.0.5: Dual Bailian Realtime Models and Dictionary Hotwords

## 🎉 New features

- Alibaba Bailian now supports switching between `Qwen Audio 3.0 ASR Flash Streaming` and `Fun-ASR Realtime`. New setups default to Qwen Audio, while existing Fun-ASR configurations remain unchanged.
- The control panel remembers the selected model, so it stays selected after changing providers or reopening the app.

## ✨ Improvements

- Terms in the Dictionary automatically use the appropriate hotword method for the selected Bailian model, improving recognition of names and specialized vocabulary.
- Each dictation uses exactly the model you selected. If an error occurs, Mouthpiece no longer silently switches to another model, keeping behavior consistent with your settings.
