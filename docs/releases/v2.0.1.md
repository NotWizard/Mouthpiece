# v2.0.1: 媒体暂停、Escape 恢复、粘贴稳定 / Media Pause, Escape Restored, Reliable Paste

## ✨ 改进

- 打开安装包（DMG）后恢复了熟悉的引导布局：左侧是 Mouthpiece，右侧是“应用程序”文件夹，中间用箭头提示你把图标从左往右拖入完成安装。

## 🐛 问题修复

- 修复使用支持“思考”的文本处理模型(如百炼 qwen3.x)时,录音结束后长时间卡在“正在润色”的问题。现在默认不触发模型深度思考,整理更快;等待超时也更短;按 Escape 可立即中断。
- 修复关闭控制面板窗口后，从菜单栏点“打开控制面板”没有任何反应、面板再也打不开的问题。现在无论关闭多少次，都能从菜单栏稳定重新打开。
- 修复设置里“听写时暂停其他媒体”打开后，在 macOS 15.4 及更高版本（含 macOS 26 Tahoe）实际上没有暂停任何媒体的问题。现在在 Chrome、Safari、Music、Spotify 等正在播放的应用上都能正确暂停，听写结束会自动继续播放。
- 修复自动粘贴转录结果在终端(如 Ghostty)、浏览器、Electron 类或较慢的应用中偶发“粘不进去”的问题。现在在这些应用里都能稳定插入,粘贴前会先把目标应用置于前台,并等它读取完再恢复剪贴板。
- 修复开启“Escape 取消录音”后，使用一段时间 Escape 键会在所有应用中失灵、按下毫无反应的问题。现在只有在录音进行时 Escape 才用于取消，其余场景一律正常传递。
- 修复在“文字处理 → 编辑 → 测试”页面试用 Prompt 时，整理结果被粘贴到你上一个使用的应用、而不是测试输入框里的问题。

## ✨ Improvements

- The installer (DMG) window again opens with the familiar layout: Mouthpiece on the left, the Applications folder on the right, and an arrow guiding you to drag it across to finish installing.

## 🐛 Bug fixes

- Fixed dictation getting stuck at "Refining…" for a long time when the text-processing model supports "thinking" (e.g., Bailian qwen3.x). Cleanup no longer triggers the model's deep thinking by default (much faster), the wait timeout is shorter, and pressing Escape interrupts it immediately.
- Fixed the menu-bar "Open Control Panel" doing nothing once you had closed the control panel window, leaving no way to bring it back. It now reopens reliably from the menu bar no matter how many times you close it.
- Fixed “pause other media during dictation” doing nothing on macOS 15.4 and later (including macOS 26 Tahoe). Chrome, Safari, Music, Spotify and other now-playing apps are now paused correctly while you dictate, and playback resumes automatically afterwards.
- Fixed automatic paste occasionally inserting nothing in terminals (such as Ghostty), browsers, Electron, or busy apps. Text now inserts reliably in these apps: the target app is brought to the front first, and the clipboard is restored only after it has had time to read the transcript.
- Fixed the Escape key becoming unresponsive in every app after using Mouthpiece for a while when “Escape cancels recording” was enabled. Escape now only cancels while a recording is in progress and passes through normally everywhere else.
- Fixed testing a prompt under Text Processing → Edit → Test inserting the cleaned-up result into your previously used app instead of the test field.
