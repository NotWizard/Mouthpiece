# v2.0.4: 紧急修复阿里云百炼听写崩溃

紧急修复 v2.0.3 的一个严重问题：使用阿里云百炼（Fun-ASR）实时听写时，开始说话后应用立即崩溃退出。使用百炼的用户请尽快升级。

## 🐛 Bug 修复

- 修复了选用阿里云百炼实时听写时，开始转录不到一秒应用即崩溃闪退的问题（v2.0.3 引入）。其他转录服务不受影响。

# v2.0.4: Hotfix for Alibaba Bailian Dictation Crash

An urgent fix for a serious v2.0.3 issue: dictating with the Alibaba Bailian (Fun-ASR) realtime service crashed the app moments after you started speaking. Bailian users should update right away.

## 🐛 Bug fixes

- Fixed the app crashing within a second of starting transcription when Alibaba Bailian realtime dictation is selected (introduced in v2.0.3). Other transcription services were not affected.
