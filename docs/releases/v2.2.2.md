# v2.2.2: 麦克风恢复、开头保留、取消更稳 / Microphone recovery, preserved beginnings, safer cancellation

开始录音时暂时收不到声音，会先尝试恢复，减少手动切换麦克风的次数。

## 🐛 问题修复

- 麦克风启动后没有送来音频时，自动重新连接一次；仍失败时保留具体原因，方便排查。
- 保留启动等待期间的声音，减少开头遗漏；快速取消并重新录音时，上一次启动结果不会打断新录音。
- 取消或关闭引导页的麦克风测试时，同时停止尚未完成的录音准备。

本次针对开始录音时的恢复。MiRemoteV 和猛玛的睡眠唤醒、设备重连仍待实机验证。

## English

When a microphone initially provides no audio, recording now attempts recovery before asking you to switch inputs manually.

## 🐛 Bug fixes

- Retry the microphone connection once when startup produces no audio, and retain the specific error if recovery fails.
- Preserve audio captured during startup so the beginning is retained. A cancelled startup no longer interrupts a replacement recording.
- Cancelling or closing the onboarding microphone test also stops pending recording preparation.

This update targets recording startup. Sleep/wake and reconnection with MiRemoteV and MOMA microphones still need physical verification.
