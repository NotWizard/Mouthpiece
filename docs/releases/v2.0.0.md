# v2.0.0: 原生 macOS、低占用与可靠听写 / Native macOS, Lower Overhead, Reliable Dictation

## ⚠️ 使用前须知

Mouthpiece 2.0 为了降低后台占用、改善系统权限稳定性并更好地适配多显示器，已完整改写为 macOS 原生应用。

- 新版本只支持 macOS 15 Sequoia 与 macOS 26 Tahoe，不再提供 Windows、Linux 或 macOS 14 及更早版本。仍在使用这些系统的用户应继续保留 Mouthpiece 1.4.8。
- macOS 用户可以直接覆盖安装，或继续使用 Homebrew 升级。首次启动会先备份并迁移原有设置、API Key、历史记录和本地模型位置，无需重新配置。
- 应用名称、安装位置、Bundle ID 和签名身份保持不变。正常覆盖安装后，麦克风和辅助功能授权应继续有效；若系统仍提示授权，请在“系统设置 > 隐私与安全性”中确认 Mouthpiece 已启用。

## 🎉 新功能

- 控制面板、首次使用引导、菜单栏和录音胶囊全部改为原生 macOS 界面，语言、主题、麦克风、快捷键、权限和模型设置保持在同一套清晰结构中。

- 原生版本继续支持百炼、Deepgram、Soniox 和 AssemblyAI 实时听写，也可使用 OpenAI、Groq、Mistral、自定义服务，以及 Whisper、Parakeet、Qwen ASR 和本地文字整理模型。

## ✨ 改进

- 控制面板关闭或隐藏后不再保留浏览器渲染进程，空闲时几乎不产生 CPU 活动，也不会持续占用 GPU。
- 快捷键、麦克风采集、文本插入和登录启动直接使用 macOS 系统能力，启动录音和插入结果更及时。
- 录音胶囊会跟随当前显示器和 macOS 桌面，并记住每台显示器上的拖动位置；外接显示器、全屏应用和睡眠唤醒后的显示更稳定。
- 已下载的本地模型会从当前或旧版目录直接复用，升级时不需要重新下载。调试日志只保留最近 7 天。
- 应用内更新、GitHub Release 与 Homebrew 继续使用同一套版本，支持安装、升级和重新安装。

## 🐛 问题修复

- 修复长时间闲置后首次录音偶发无法进入实时识别、连接断开或等待超时的问题；实时连接不可用时会保留录音并使用同一服务完成识别。
- 修复外接显示器或切换 macOS 桌面后，录音已经开始但胶囊仍停留在其他屏幕空间的问题。
- 修复安静环境、短暂停顿或较轻声音可能被过早丢弃的问题，同时避免把纯静音录音发送给识别服务。
- 修复目标应用短暂忙碌时被误判为辅助功能权限丢失，以及恢复剪贴板时覆盖用户刚复制内容的问题。

## ⚠️ Heads-up

Mouthpiece 2.0 has been rebuilt as a native macOS app to reduce background resource use, improve permission continuity, and behave more reliably across displays.

- This release supports macOS 15 Sequoia and macOS 26 Tahoe only. Windows, Linux, and macOS 14 or earlier are no longer supported; users on those systems should remain on Mouthpiece 1.4.8.
- macOS users can install over the existing app or continue upgrading through Homebrew. On first launch, Mouthpiece backs up and migrates existing settings, API keys, history, and local model locations automatically.
- The app name, installation path, bundle identifier, and signing identity remain unchanged. Microphone and Accessibility permissions should carry over after a normal in-place update. If macOS still asks, confirm that Mouthpiece is enabled under System Settings > Privacy & Security.

## ✨ Improvements

- Closing or hiding the control panel no longer leaves a browser renderer behind. The idle app produces virtually no CPU activity and does not continuously use the GPU.
- Hotkeys, microphone capture, text insertion, and login launch now use macOS system services directly for faster recording startup and result insertion.
- The dictation capsule follows the active display and macOS Space, remembers its dragged position per display, and recovers more reliably after full-screen use, display changes, and sleep.
- Existing local models are reused from current or legacy locations, so upgrading does not force another download. Debug logs are retained for 7 days only.
- In-app updates, GitHub Releases, and Homebrew continue to share the same version and support install, upgrade, and reinstall workflows.

## 🐛 Bug fixes

- Fixed the first recording after a long idle period occasionally missing realtime recognition, disconnecting, or waiting for a timeout. If realtime connection is unavailable, the recording is retained and completed through the same service.
- Fixed the dictation capsule remaining on another display or macOS Space after switching desktops or using an external monitor.
- Fixed quiet speech, short pauses, or soft voices being discarded too early while preventing silent recordings from being sent for recognition.
- Fixed a temporarily busy target app being mistaken for missing Accessibility permission and clipboard restoration overwriting content copied by the user moments earlier.
