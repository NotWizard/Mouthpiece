# v2.0.0: 原生 macOS、轻快听写、稳定胶囊 / Native macOS, Responsive Dictation, Stable Capsule

## ⚠️ 使用前须知

Mouthpiece 2.0 完整改写为 macOS 原生应用，目的是显著降低后台资源占用，并让快捷键、麦克风、权限和多显示器体验更稳定。

- 新版本仅支持 macOS 15 Sequoia 与 macOS 26 Tahoe，不再提供 Windows、Linux 或 macOS 14 及更早版本。仍在使用这些系统的用户应保留 Mouthpiece 1.4.8。
- macOS 用户可以直接覆盖安装，或继续通过 Homebrew 升级。首次启动会备份并迁移现有设置、API 密钥、历史记录与本地模型位置。
- 应用名称、安装位置、Bundle ID 和固定签名身份保持不变，正常覆盖安装后已有的麦克风与辅助功能权限应继续有效。若系统再次询问，请在“系统设置 > 隐私与安全性”中确认 Mouthpiece 已开启。

## 🎉 新功能

- 全新的原生控制面板把常规设置、听写模型、文字处理、词典、历史与权限诊断分成清晰页面；首次引导会一次完成权限、快捷键和录音胶囊验证，不要求提前配置云端服务。
- 云端听写现支持百炼 Fun-ASR、火山引擎豆包流式语音识别、OpenAI、Deepgram、Soniox、AssemblyAI、Groq、Mistral 与自定义兼容服务；离线场景可继续使用 Whisper、Parakeet 和 Qwen ASR。
- 文字处理服务改为醒目的服务商选择，并支持 API 密钥自动保存、隐藏与显示、模型名称、思考模式、自定义 Prompt 和个人词典。
- 新增自动粘贴、剪贴板保留、听写时暂停其他媒体、独立翻译组合键与 7 天 Debug 日志保留控制。

## ✨ 改进

- 控制面板隐藏后不再保留浏览器渲染进程，空闲时几乎不产生 CPU 活动，也不会持续占用 GPU。
- 固定尺寸的录音胶囊会跟随当前应用所在显示器与 macOS Space，录音、处理、实时文字和错误状态之间不再上下跳动；实时文字最多显示两行并自然滚动。
- 快捷键、麦克风采集、Escape 取消、文本插入和登录启动直接使用 macOS 系统能力，首次录音与结果写入更及时。
- 历史记录改为单列卡片，可分别复制处理前后文字；所有开关、输入框、服务商图标、浅色与深色层级均按原生界面重新统一。
- Sparkle、GitHub Release 与 Homebrew 使用同一版本，继续支持安装、升级与重新安装。

## 🐛 问题修复

- 修复通过 Homebrew 或 DMG 安装后，应用可能在打开窗口前立即退出的问题。
- 修复长时间闲置后首次录音偶发无法建立实时连接、连接中断或等待超时的问题，并避免旧连接影响新的听写会话。
- 修复外接显示器、切换桌面、全屏应用或睡眠唤醒后，录音已开始但胶囊仍停留在其他屏幕的问题。
- 修复自动粘贴开启后，较长转录结束时偶发只保留在剪贴板、没有写入原输入位置的问题。
- 修复胶囊启动时短暂闪过“正在准备”，以及静音波形接近满幅、轻声被误判为无语音的问题。
- 修复 Escape 偶发无法取消、目标应用短暂忙碌时被误判为权限丢失，以及恢复剪贴板时覆盖用户新复制内容的问题。
- 修复胶囊转录文字超过两行时右侧出现多余垂直滚动条的问题。
- 修复结束录音插入文字时，目标应用无响应导致主线程冻结、快捷键与 Escape 失灵的问题。
- 修复点击 Dock 图标重新打开应用时，因 SwiftUI 重建 HostingView 解引用已损坏执行器而崩溃（EXC_BAD_ACCESS）的问题。

## ⚠️ Heads-up

Mouthpiece 2.0 has been completely rebuilt as a native macOS app to reduce background resource use and make hotkeys, microphone access, permissions, and multi-display behavior more reliable.

- This release supports macOS 15 Sequoia and macOS 26 Tahoe only. Windows, Linux, and macOS 14 or earlier are no longer supported; users on those systems should remain on Mouthpiece 1.4.8.
- macOS users can install over the existing app or continue upgrading through Homebrew. The first launch backs up and migrates existing settings, API keys, history, and local model locations.
- The app name, install location, bundle identifier, and stable signing identity remain unchanged, so existing Microphone and Accessibility permissions should normally carry over. If macOS asks again, confirm that Mouthpiece is enabled in System Settings > Privacy & Security.

## 🎉 New features

- The native control panel now separates General, Dictation Models, Text Processing, Dictionary, History, and Permissions & Diagnostics. Onboarding completes permissions, hotkey setup, and a microphone-and-capsule check without requiring a cloud provider first.
- Cloud dictation now supports Bailian Fun-ASR, Volcengine Doubao Streaming ASR, OpenAI, Deepgram, Soniox, AssemblyAI, Groq, Mistral, and custom compatible services. Whisper, Parakeet, and Qwen ASR remain available for local transcription.
- Text processing now offers visible provider selection, automatically saved and revealable API keys, model names, reasoning mode, custom prompts, and a personal dictionary.
- New controls cover automatic paste, clipboard retention, pausing other media during dictation, a separate translation chord, and automatic deletion of Debug logs after 7 days.

## ✨ Improvements

- Hiding the control panel no longer leaves a browser renderer running. The idle app produces virtually no CPU activity and does not continuously use the GPU.
- The fixed-size dictation capsule follows the target application's display and macOS Space. Recording, processing, live text, and error states no longer resize vertically, while live text scrolls naturally within two lines.
- Hotkeys, microphone capture, Escape cancellation, text insertion, and login launch now use macOS system capabilities directly for faster recording startup and result insertion.
- History uses a single card list with separate copy actions for original and processed text. Switches, fields, provider icons, and light/dark visual hierarchy now share one native design language.
- Sparkle, GitHub Releases, and Homebrew share the same version and continue to support installation, upgrades, and reinstalls.

## 🐛 Bug fixes

- Fixed the app occasionally quitting before showing a window after installation through Homebrew or a DMG.
- Fixed the first recording after a long idle period occasionally failing to establish realtime recognition, disconnecting, or waiting for a timeout, while preventing old connections from affecting a newer session.
- Fixed the capsule remaining on another display after switching Spaces, entering full screen, reconnecting a monitor, or waking the Mac.
- Fixed automatic paste occasionally leaving a completed long dictation only in the clipboard instead of inserting it at the original input position.
- Removed the brief preparing flash at capsule startup, corrected near-full waveform movement during silence, and prevented quiet speech from being mistaken for no input.
- Fixed Escape occasionally failing to cancel, a temporarily busy target app being mistaken for missing permission, and clipboard restoration overwriting newly copied content.
- Removed an unnecessary vertical scrollbar that appeared in the capsule when the transcript exceeded two lines.
- Moved blocking Accessibility text-insertion calls off the main thread with a timeout, so an unresponsive target app can no longer freeze the capsule or break hotkey/Escape cancellation.
- Intercepted the dock-reopen event so re-activating the app brings the existing window forward instead of rebuilding the SwiftUI hosting view, which crashed with EXC_BAD_ACCESS by dereferencing a corrupted executor.
